# Admin Runbook

## 登录后台

启动前后端后访问：

```text
http://localhost:5173/admin
```

默认账号来自 `.env`：

```text
ADMIN_EMAIL=admin@qingzhuo.local
ADMIN_PASSWORD=change-this-password
```

首次真实使用前请修改默认密码，并把 `.env` 中的 `JWT_SECRET` 换成长随机值。

## 订单处理

1. 打开“订单处理”。
2. 查看待付款订单。
3. 线下确认微信/支付宝扫码到账后，点击“确认付款”。
4. 付款确认后填写快递公司和单号，点击“标记发货”。
5. 用户收货或演示流程结束后，点击“标记完成”。

取消和退款当前是人工流程标记，不会调用支付平台退款 API。

## 商品库存

“商品库存”用于：

- 新增商品和首个 SKU。
- 上架/下架商品。
- 调整 SKU 价格。
- 调整库存。
- 启用/停用 SKU。

前台只展示 `ACTIVE` 商品和 `ACTIVE` SKU。

## 收款方式

“收款方式”用于维护扫码付款信息：

- 类型：微信或支付宝。
- 显示名称。
- 二维码图片路径。
- 付款说明。
- 启用/停用。

前台下单成功后只展示启用的收款方式。

## 管理员账号

OWNER 管理员可以：

- 创建 STAFF 或 OWNER 账号。
- 禁用管理员。
- 重置管理员密码。

普通 STAFF 可以处理订单和维护商品/收款方式，但不能管理管理员账号。

## 审计日志

“操作审计”展示敏感后台动作，例如管理员创建、密码重置和订单状态更新。商品和收款方式维护当前不写审计日志，后续需要更严格追踪时可以扩展。
